RunMethod パラメータ & 軌跡プレビュー

実機と同じ src/RunMethod/EdgePidRunning.js を、仮想コース（白地に黒ライン）の上で走らせます。 Kp / Ki / Kd を動かすと軌跡と偏差の応答が変わります。

走行方式

PID パラメータ（RunInfo）

微分項は1周期（10ms）差分なので、以前の「200ms前との差」だった頃より大きな Kd が要ります。 直線なら Kd 60 前後で整定が 6.0s から 2.0s に縮みます。Kd を 0 に戻すと振動が収まらなくなる様子が見られます。

目標反射光 = (黒 + 白) / 2 − (黒 − 白) × WPER / 100
→ 現在の目標値: 32.5

既定値は public/config/2026/robot.yaml の black_threshold / white_threshold と同じです。

仮想コース

走行体はライン幅 20mm を基準に実寸比（車輪間隔 125mm / 車輪径 55mm）で描いています。 既定の 12.0 はこの縮尺で車軸の 60mm 前方にあたります。実機（およそ 100mm 前方 = 20 前後）まで 伸ばすこともできますが、先読み距離が変わるため既定ゲインのままだと整定しなくなります。

形状によって必要なゲインが違うことを確かめられます。微分項を1周期差分に変えてからは Kd を大きく取る必要があり、既定（Kp 2 / Kd 10）でまともに追従するのは直線だけです。 S字・円弧・90度コーナーはゲインを上げないとラインを外れます。

形状ゲインの例RMS ずれ備考
直線Kp 2 / Kd 600.19整定 2.0s。既定（Kd 10）だと 0.25・整定 6.0s
S字Kp 6 / Kd 1000.73Kd 10 では 13.5 まで悪化して追従しない
円弧Kp 10 / Kd 1004.4曲率一定の入力には偏差が残り、内側を回る
90度コーナーKp 8 / Kd 1000.25Kd 10 では角で外れる（Kp 6 / Kd 10 で 0.58）

計測条件: FWD 50 / TRN 0 / Ki 0 / 1000 ステップ / ライン幅 4.0 / ぼけ幅 1.5、その他は既定値。

モータモデル（エンコーダ）

ω += Ts × (α·u − β·ω − J·τc·sign(ω) − J·τload)
θ += Ts × ω  /  エンコーダ値 = floor(θ)
現在値: θ = 0 / ω = 0
